Interactive explorer for bayesiancl

Bayesian clustering of the Iris dataset (petal area vs. sepal area). Drag the slider to change the upper bound k, which is the number of prior means given to ProdForm (K-Means centres are used as priors). Hover over a point to see the flower's details.

3
–clusters found by ProdForm

–ARI K-Means

Colours are matched to the true species, so the same group has the same colour in every panel. ARI is the adjusted Rand index against the true species (1 = perfect agreement). All results are produced by the bayesian_clustering package with notebooks/make_explorer_data.py (ProductForm(sampling_size=500), seed 42).
